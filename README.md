# GrowLand v4 | گرولند

سامانه ردیابی رشد و توسعه فردی (React + Vite + Supabase)

## ارتقا از نسخه قبل (ترتیب مهم است)

1. **اول دیتابیس:** محتوای `supabase.sql` را در Supabase › SQL Editor اجرا کنید.
   - روی دیتابیس زنده امن است، هیچ داده‌ای حذف نمی‌شود و چندبار اجرا کردنش مشکلی ندارد.
   - اگر خطا داد، کل اسکریپت برگشت می‌خورد (یک تراکنش است) و چیزی نیمه‌کاره نمی‌ماند؛ متن خطا را برایم بفرستید.
2. **بعد کد:** فایل‌ها را جایگزین کنید و روی GitHub پوش کنید (Vercel خودکار دیپلوی می‌کند).
   - **`src/config.js` را بازنویسی نکنید** (مقدار واقعی Supabase شما داخل آن است) یا به‌جایش در Vercel › Settings › Environment Variables دو متغیر `VITE_SUPABASE_URL` و `VITE_SUPABASE_KEY` را ست کنید (اولویت با متغیرهاست).
3. یک‌بار روی سیستم خودتان `npm install` بزنید و `package-lock.json` ساخته‌شده را کامیت کنید تا بیلد تکرارپذیر شود.

> ترتیب را برعکس نکنید: کد جدید به توابع و نماهای جدید دیتابیس (`submit_report`، `leaderboard` و ...) نیاز دارد.

## اجرا
- `npm install` سپس `npm run dev`
- `npm test` — تست خودکار قوانین بازی (بدون نیاز به نصب چیزی)
- `npm run lint` / `npm run format`
- مهاجرت‌های دیتابیس: پوشه `supabase/migrations` (برای Supabase CLI: `supabase link` و `supabase db push`). `supabase.sql` همان مجموعه به‌صورت یک فایل است.

## قوانین
- گزارش «امتیازدار»: حداقل ۱۵۰ حرف، ۱۵ کلمه و تنوع حرف کافی؛ ۱۰۰ XP؛ حداکثر ۳ گزارش امتیازدار در روز؛ متن تکراری (۳۰ روز اخیر) XP ندارد.
- فقط گزارش امتیازدار در XP، زنجیره فعالیت، نمودار هفتگی و دستاوردها حساب می‌شود (یک تعریف برای همه).
- هر ۱۰۰۰ XP یک لول. «امروز» همیشه به وقت تهران و ساعت سرور است.
- گزارش بدون XP تا قبل از بررسی قابل ویرایش/حذف توسط خود عضو است؛ گزارش امتیازدار تغییرناپذیر است.
- هر تغییر XP (گزارش یا ادمین) در جدول `xp_events` ثبت می‌شود.
- تغییر قوانین: هم `src/rules.js` و هم تابع `gl_cfg()` در دیتابیس را به‌روز کنید.

## ساختار
```
src/
  rules.js        قوانین و توابع خالص (تست‌شده)
  db.js           کلاینت Supabase، storage امن، ساعت سرور
  api.js          تمام فراخوانی‌های دیتابیس + تبدیل خطا به پیام فارسی
  hooks.js        useQuery (کش)، usePaged، useAction، useLive (Realtime)
  notify.jsx      Toast و جشن ارتقای سطح (Context)
  router.js       روتر hash (Back مرورگر، لینک مستقیم)
  ui.jsx          کامپوننت‌های ظاهری      widgets.jsx  Growth / Thread / پروفایل
  pages/          پنج صفحه اصلی           Admin.jsx · Auth.jsx · Landing.jsx · App.jsx
supabase/migrations/   مهاجرت‌های دیتابیس
```

## محدودیت‌های شناخته‌شده (عمدی)
- احراز هویت هنوز سفارشی است: رمز عبور متن ساده ذخیره می‌شود و RLS خاموش است (طبق تصمیم قبلی پروژه). قوانین بازی در دیتابیس اجرا می‌شوند، ولی چون کلید anon به همه‌ی جدول‌ها دسترسی دارد، یک کاربر فنی می‌تواند مستقیم جدول‌ها را دستکاری کند. راه‌حل واقعی: Supabase Auth + RLS.
- ایمیل/SMS اضافه نشده است.
- رمز سوپر ادمین پیش‌فرض را بعد از ورود از «پروفایل» عوض کنید.

## نصب روی موبایل (PWA)
- پروژه یک PWA کامل است: `public/manifest.webmanifest`، `public/sw.js`، `public/offline.html` و آیکون‌های PNG.
- **اندروید (Chrome):** سایت را روی HTTPS باز کنید؛ دکمه «نصب اپ» ظاهر می‌شود (یا منوی ⋮ ← Install app).
- **آیفون (Safari):** Share ← Add to Home Screen.
- سرویس‌ورکر فقط در نسخه build فعال است (`npm run build && npm run preview`). درخواست‌های Supabase هرگز کش نمی‌شوند.
- بعد از هر انتشار مهم، `VERSION` را در `public/sw.js` بالا ببرید.

## قابلیت‌های موبایل (V4.1)
- **ثبت آفلاین گزارش:** با قطعی اینترنت گزارش در گوشی ذخیره و با اتصال خودکار ارسال می‌شود؛ پیش‌نویس هم خودکار ذخیره می‌شود. اپ نصب‌شده بدون اینترنت هم باز می‌شود.
- **بروزرسانی:** نسخه‌ی جدید که منتشر شود، نوار «بروزرسانی» نشان داده می‌شود. عدد `VERSION` در `public/sw.js` را بالا ببرید.
- **UI:** تم خودکار (از تنظیم گوشی)، لرزش (haptic)، Pull-to-refresh، نوار پایین هوشمند + دکمه شناور گزارش، اسکلت بارگذاری، انتقال نرم صفحه، عدد روی آیکون اپ، میانبرهای آیکون (گزارش/پیام/اعضا).
- **چالش‌های هفتگی** (در پنل رشد) و **کارت دستاورد قابل اشتراک‌گذاری** (تصویر PNG).

## راه‌اندازی اعلان پوش (یک‌بار)
1. `npm install` (وابستگی `web-push` اضافه شده) و `npx web-push generate-vapid-keys`
2. در **Vercel > Settings > Environment Variables**: `VITE_VAPID_PUBLIC_KEY`، `VAPID_PRIVATE_KEY`، `VAPID_SUBJECT`، `SUPABASE_SERVICE_KEY`، `WEBHOOK_SECRET`، `CRON_SECRET` (توضیح در `.env.example`) سپس Redeploy.
3. در Supabase SQL Editor فایل `supabase/migrations/20261125000000_push.sql` (یا کل `supabase.sql`) را اجرا کنید.
4. برای اعلان پیام‌ها: `supabase/push-webhooks.sql` را (بعد از جایگزینی دامنه و `WEBHOOK_SECRET`) اجرا کنید.
5. یادآوری روزانه‌ی ۱۸:۰۰ تهران با Vercel Cron (`vercel.json`) خودکار فعال است.
هر کاربر اعلان را از «پروفایل ← فعال‌سازی اعلان‌ها» روشن می‌کند. روی آیفون ابتدا باید اپ به Home Screen اضافه شود.

## نسخه ۵ — سرعت و مدیریت (ترتیب ارتقا مهم است)
1. **اول دیتابیس:** `supabase/migrations/20261126000000_v5_speed_admin.sql` (یا کل `supabase.sql`) را در SQL Editor اجرا کنید.
2. **بعد کد** را جایگزین و `npm install` کنید (وابستگی `@supabase/postgrest-js` اضافه شد) و `VERSION` در `public/sw.js` را بالا ببرید (در این نسخه `v3`).

### بهینه‌سازی‌ها
- بوت اپ در **یک درخواست** (`app_boot`) و نشانگرها در یک درخواست (`app_badges`)؛ قبلاً ۵–۸ درخواست پشت‌سرهم بود.
- اپ با پروفایل ذخیره‌شده **فوراً** باز می‌شود (بدون اسپینر) و داده‌ی تازه پشت صحنه می‌آید؛ کش درخواست‌ها هم بین بازشدن‌ها ذخیره می‌شود.
- جلوگیری از درخواست تکراری هم‌زمان (in-flight dedupe)، لیست اعضا + مهارت‌ها در یک درخواست (`members_page`)، رتبه بدون محاسبه‌ی پنجره روی کل جدول (`gl_rank_of`)، ایندکس trigram برای جستجو.
- Realtime/WebSocket حذف شد (روی شبکه‌های ناپایدار کندکننده بود و با هر پیام در کل سیستم همه‌ی کاربران را درخواست‌باران می‌کرد)؛ polling سبک جایگزین شد. بسته‌ی جاوااسکریپت هم به‌خاطر حذف `supabase-js` از سمت کلاینت کوچک‌تر شد.
- سرویس‌ورکر: صفحه‌ی اصلی فوراً از کش باز می‌شود و فایل‌های هش‌دار بدون درخواست اضافه خوانده می‌شوند.
- CSS: حذف blur سنگین پس‌زمینه و backdrop-filter، سایه‌های سبک‌تر، `content-visibility` برای لیست‌ها.

### مدیریت
- حذف گزارش (تکی، گروهی، یا همه‌ی گزارش‌های یک عضو) با گزینه‌ی برگرداندن XP و فعالیت.
- حذف عضو: دکمه‌ی «حذف عضو» بالای ویرایشگر؛ سوپر ادمین هر کسی (جز خودش) و ادمین اعضای تحت سرپرستی خودش را حذف می‌کند. سوپر ادمین‌ها هم از تب «نقش‌ها» قابل تغییر نقش‌اند.
- پنل ادمین ریسپانسیو: ویرایشگر عضو روی موبایل صفحه‌ی کشویی است و جدول‌ها کارتی می‌شوند.
